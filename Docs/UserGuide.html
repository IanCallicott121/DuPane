Introduction

What is DuPane?

DuPane is a full-featured file manager for macOS power users — a native dual-pane workspace where copy, move, compare, script, and inspect operations are always within reach. Both keyboard and mouse are fully supported throughout.

Where Finder is built for casual browsing, DuPane is built for work. Every feature is designed to eliminate friction: no window juggling, no switching to Terminal, no hunting for Get Info. The two-pane layout means your source and destination are always visible. The integrated terminal means your shell commands run in-context. Bookmarked folders in the sidebar mean your frequently-used locations are one click away.

⊞

Dual Panes

Two independent folder views with separate navigation history, tabs, sort, and filter. Move or copy files with one click — no window juggling.

◉

Smart Metadata

Dimensions for images, duration for video/audio, line count for code files — shown in the Info column (enable it via right-click on any column header), loaded in the background.

📑

Pinned Tabs + Persistence

Pin important folders so they survive navigation, recall their exact location with one click, and persist across all restarts.

⊙

Folder Size Chart

Visualise which subfolders are consuming your disk space in a live proportional bar chart, scanning the full tree in the background.

⇄

Compare & Sync

Compare the two active folders side-by-side, with per-row difference highlights (newer, older, different, only here), then sync in one click.

$_

Integrated Terminal

A retractable shell panel lives at the bottom of each pane. Commands run in the current directory — stay in context, never switch windows.

⊟

Column Control

Show, hide, resize, and reorder columns. Global sort column and direction. Font size adjustable from 11–16 pt. Everything adapts and persists.

Everything customisable, everything persistent

Unlike Finder — where each window starts fresh — DuPane remembers your tabs (including names, colours, and pinned state), column widths and order, sidebar bookmarks, startup folders, and custom actions across restarts. Start work exactly where you left off.

💡

Inspired by Directory Opus (Windows) and Total Commander, DuPane brings the same power-user file management philosophy to macOS as a fully native SwiftUI application — no Electron, no performance compromises.

Getting Started

Why DuPane? Can't I just use Finder?

Finder is excellent for casual browsing — it wasn't designed for heavy file work. DuPane is built for developers and power users who move dozens of files a day, juggle multiple project directories, and want their shell, their file tree, and their operations in one keyboard-friendly place.

The dual-pane advantage

The single biggest productivity gain: two folder views, side by side, at all times. In Finder you open a source window, arrange it next to a destination window, and hope your drag lands in the right place. In DuPane you select files in the left pane and press Move — the right pane is always the destination. No window juggling, no missed drops, no accidental copies.

But DuPane goes far beyond dual-pane. Every feature is chosen to eliminate a specific friction point that power users hit daily:

Why DuPane is particularly good for developers

Every developer workflow DuPane targets maps to a concrete feature:

  • Deploying build artefacts? Split-pane: source on left, server mount on right. Select all, Copy. Done.
  • Refactoring a project tree? Compare mode shows which files differ between two branches (checked out in separate directories). Sync selectively.
  • Stripping metadata from build outputs? Custom Action: exiftool -all= $@. One right-click, runs on every selected file.
  • Checking image assets? Enable the Info column (right-click any column header) — pixel dimensions appear inline for every image, no Inspector needed.
  • Jumping between multiple projects? Bookmark each project root — the sidebar gets you there in one click.
  • Running git commands? Command Runner is already in the pane — type git status without opening a separate terminal.
💡

DuPane doesn't replace Finder — it complements it. Right-click any file → Reveal in Finder when you need Finder-specific features (AirDrop, Tags from colour wheel, iCloud status). For day-to-day file work, you'll rarely need to switch.

Getting Started

Quick Start

You'll be navigating files in under a minute. Here's the essential workflow.

  1. Launch DuPane. The left pane opens your Downloads folder; the right pane shows Computer (all mounted volumes). Click any volume to enter it. On first launch macOS will ask for permission to access your Downloads and Documents folders — click Allow for each prompt. These prompts appear once and are remembered.
  2. Click a pane to make it active. The active pane shows a coloured border. Navigation commands always target the active pane.
  3. Double-click a folder to enter it. Use the breadcrumb trail at the top or the ↑ button to go up a level.
  4. Select files with a single click. Hold ⌘ to add items to the selection, or ⇧ to select a range.
  5. Press Space to Quick Look the selected file(s) without leaving DuPane.
💡

Tip: Use ⌘T to open a new tab and work on two paths within the same pane simultaneously.

Permission Indicator

Folders you don't have read access to show a small red lock badge on their icon. Attempting to navigate into them will show an error — but you can still copy or move files to them if you have write access at the filesystem level.

Switching Between Panes

Simply click anywhere inside the desired pane. The coloured border shows which pane is active. All toolbar actions (Move, Copy, Delete, New Folder) operate on the active pane.

Status Bar

Each pane has a status bar at its bottom edge showing the item count, how many items are selected, and the total size of the selection (e.g. 24 items, 3 selected (14.2 MB)). When a filter is active it appends (filtered). When exactly one file is selected, the Smart Metadata value for that file — such as image dimensions, video duration, or line count — appears after a · separator.

Follow Mode

Click the Follow button in the toolbar to enable Follow Mode. When active (the button glows blue), any folder you navigate to in the active pane is immediately mirrored to the inactive pane. Enabling Follow Mode also snaps the inactive pane to the active pane's current folder straight away.

Follow Mode is useful when you want both panes to always show the same directory tree — for example, when exploring a project structure alongside a destination. Click Follow again to turn it off.

DuPane disables the system-level macOS window tab bar so there is only one tab model to manage. Use the tab strip inside each file pane for all tab workflows.

Core Features

Sidebar & Bookmarks

The sidebar gives you one-click access to favourite locations, recently visited folders, and user bookmarks — organised into clear sections.

Toggle the sidebar with ⌥⌘S or the Sidebar button in the toolbar. Click any location to navigate the active pane there instantly. Hovering over any row highlights it, so it is always clear which item will be activated by a click or right-click.

To resize the sidebar, drag the divider between the sidebar and the file panes left or right. The width is saved and restored across restarts. Minimum width is 120 pt, maximum 320 pt.

Places

The Places section shows fixed system locations for instant one-click access: Home, Applications, Desktop, Documents, and Downloads. If iCloud Drive or OneDrive is configured on your Mac, those folders also appear here automatically. You can choose which locations appear in Settings → Sidebar Places — each can be toggled on or off independently.

Recents

The Recents section automatically tracks the last 12 folders you navigated to in either pane — no configuration needed. The most recently visited folder appears at the top. Right-click any recent item to remove it, or click Clear Recents to reset the entire list.

The sidebar also includes a Tags section when Finder tags are present in the loaded panes or Spotlight results. The full tag row is clickable. Click a tag to filter both panes to items with that tag; selected tags keep a highlighted background. Click the only selected tag again to clear the filter. ⌘-click additional tags to include more than one tag in the filter.

Locations

The Locations section appears automatically when external drives are attached — USB drives, Thunderbolt drives, SD cards, and optical media. Click any entry to navigate the active pane to the drive root. Right-click for Eject to unmount the drive cleanly. The section disappears when no external drives are connected.

Network

When Settings → Sidebar → Show Network section is enabled (the default), a Network section appears at the bottom of the sidebar. Each sub-feature can be toggled individually in Settings → Network.

Mounted network volumes

Any currently-mounted network share (SMB, AFP, NFS, WebDAV, etc.) appears in the Network section with its volume name. Click an entry to navigate the active pane to the share root. Right-click a mounted share for Open in Pane, Pin to Network Sidebar, or Eject (which unmounts it). The list updates automatically when shares are mounted or unmounted. Toggle with Settings → Network → Show mounted network volumes.

Status indicator

A small coloured dot precedes each network entry: ● green for a currently-mounted share, and ● grey for a pinned server that is not yet mounted. Toggle with Settings → Network → Show status indicator.

Pinned servers

Right-click any mounted network volume and choose Pin to Network Sidebar to save its URL persistently. Pinned entries stay in the Network section even when not mounted — click one to connect, or right-click for Connect Now, Rename…, or Remove from Pinned. Toggle visibility with Settings → Network → Show pinned servers.

Connect to Server

Click Connect to Server… to open the connection sheet. Type a server address — for example smb://server/share, afp://server/share, or nfs://server/path — and press ⏎ or click Connect. macOS handles authentication (prompting for credentials if the share is not already in Keychain) and mounts the share under /Volumes/.

Bonjour discovery

When Settings → Network → Bonjour discovery in Connect sheet is on, the Connect sheet scans the local network for SMB (_smb._tcp) and AFP (_afpovertcp._tcp) services using Bonjour. Discovered servers appear in a scrollable list — click any entry to populate the address field automatically. Browsing starts when the sheet opens and stops on close.

Auto-reconnect on launch

When Settings → Network → Auto-reconnect pinned servers on launch is on (default off), DuPane silently attempts to mount each pinned server at startup. This works seamlessly when credentials are stored in the macOS Keychain from a previous connection.

Adding Bookmarks

There are two ways to add a bookmark:

  • Toolbar button: Select exactly one file or folder, then click the Bookmark button in the toolbar.
  • Right-click: Right-click any file or folder → Bookmark to add it directly from the context menu.

The item appears immediately in the sidebar's Bookmarks section.

Opening Bookmarks

Clicking a bookmarked folder navigates the active pane there. Clicking a bookmarked file opens it in its default application. Folder bookmarks show a folder icon; file bookmarks show a document icon — making it easy to tell them apart at a glance.

Clicking a bookmarked shell script (.sh file) shows a confirmation dialog before executing it in Terminal — shell scripts can modify or delete files, so you'll never accidentally run one.

Renaming Bookmarks

Right-click a bookmark and choose Rename… to give it a custom display label. The label is shown in the sidebar in place of the filename. Removing the bookmark also removes the custom label. Removing the text entirely in the rename sheet restores the original filename.

Reordering Bookmarks

Right-click a bookmark and choose Move Up or Move Down to shift it one position in the list. You can also drag bookmarks to a new position directly in the sidebar.

Removing Bookmarks

Hover over a bookmark in the sidebar — a × button fades in on the right. Click it to remove. You can also right-click a bookmark and choose Remove Bookmark, or select the bookmarked item and click the Bookmark toolbar button again to toggle it off.

Moving & Copying

Select files or folders in the active pane, then click Move → or Copy ⎘ in the toolbar. Items are sent to the other pane's current directory.

You can also drag selected files or folders between panes. A plain drag moves the selection; holding Option during the drag copies it instead. Directory rows accept drops into that subfolder (blue outline on hover), while file rows and the pane background drop into the current folder. Files dragged in from Finder or other apps are always copied, never moved.

You can also right-click any file or folder to get Move to [folder] and Copy to [folder] options in the context menu.

For operations that take more than about 400 ms (typically large files or many items), a compact progress pill appears at the bottom of the window showing the operation label, a progress bar, and an item count (N of M). The pill fades away automatically when the operation completes. Quick single-file copies finish before the pill ever appears, so there is no visual noise for routine operations.

Conflict resolution

If one or more items being transferred already exist in the destination, a dialog appears with three choices:

  • Overwrite — replaces the existing item in the destination.
  • Skip — leaves existing items untouched; only non-conflicting items are transferred.
  • Keep Both — auto-renames the incoming item with a numeric suffix (e.g. report 2.pdf, report 3.pdf, …), preserving both the original and the new file.
⚠️

The other pane must be inside a real folder (not the Computer root) for Move/Copy to work. Navigate the inactive pane to the destination first.

Deleting

Select files or folders and press ⌘⌫ or click the 🗑 Delete toolbar button. A confirmation dialog appears (configurable in Settings). Items are always moved to the macOS Trash — you can recover them from the Trash if you change your mind.

Duplicate

Right-click any file or folder → Duplicate to create a copy in the same folder. The copy is named filename copy (with a counter if that name already exists). Works on the full selection.

Compress & Uncompress

Right-click → Compress to zip the selected file(s) into a .zip archive in the same folder. The archive is named after the single selected item, or Archive.zip for multiple items.

Uncompress a .zip file in two ways: right-click it and choose Uncompress, or simply double-click it. Both extract the archive into the same folder, keeping you in DuPane the whole time. If any file in the archive already exists at the destination, a dialog appears with three options: Overwrite (replace existing files), Skip existing (keep existing files and extract only the new ones), or Cancel.

Copy & Share

Right-click → Copy places the selected file(s) on the macOS clipboard so you can paste them into Finder, Messages, Mail, or any other app that accepts files.

Right-click → Share… opens the standard macOS sharing sheet — AirDrop, Messages, Mail, Notes, and any other configured sharing service.

Open With…

Right-click any file → Open With… to choose a specific application to open it. The submenu shows up to 8 compatible apps. Choose Other… to browse to any app in /Applications.

Copy Path

Right-click any file → Copy Path to place the full POSIX path on the clipboard — handy for pasting into Terminal or code editors.

Reveal in Finder

Right-click any file → Reveal in Finder to highlight the item in a standard Finder window.

Bookmark from Context Menu

Right-click any file or folder → Bookmark to add it to the sidebar's Bookmarks section. If the item is already bookmarked, the option reads Remove Bookmark to toggle it off.

Get Info

Right-click any file or folder → Get Info… to open a detail sheet showing the item's icon, name, kind, full path, size, modified date, created date, and any colour tags. File size is loaded from disk asynchronously for maximum accuracy.

Shell Scripts

Double-clicking a .sh file (or clicking a bookmarked .sh in the sidebar) shows a confirmation dialog. Click Execute to run the script in a new Terminal window, or Cancel to leave it unopened. This prevents accidentally running scripts that could modify or delete files.

Folder Compare & Sync

Compare mode checks the active folders in the left and right panes, highlights differences, and lets you sync eligible changes in either direction after a confirmation preview.

Starting a Compare

  1. Navigate both panes into real folders. Compare is disabled while either pane is at the Computer root.
  2. Click the Compare button in the main toolbar.
  3. Rows are highlighted and badged when an item is only on one side, newer on one side, older on one side, or different.
StatusMeaning
only hereThe item exists in this pane but not in the other pane.
newerThe item matches by name, kind, and size, but this pane has the newer modified date.
olderThe matching item in the other pane has the newer modified date.
differentThe name matches, but kind, size, or date information conflicts.

Syncing Changes

When Compare mode is active, the toolbar shows Sync L->R and Sync R->L. A sync copies missing source-side items and overwrites eligible older or different files on the destination side. A confirmation dialog lists the planned copy and overwrite counts before anything is written.

⚠️

Sync never deletes destination-only items. Missing folders can be copied, but existing folder differences are skipped in this version because Compare does not yet scan inside folders.

Sorting & Filtering

Click any column header to sort; click again to reverse. The active sort column shows a small arrow indicating direction.

Sorting

Click the column headers — Name, Size, Kind, Modified, or Info — to sort by that column. Click the same column again to reverse the direction. A small arrow shows the current sort direction.

Showing and Hiding Columns

Right-click any column header to reveal a context menu that lets you show or hide the file icon and any of the four optional metadata columns: Icon, Size, Kind, Modified, and Info. The Name column is always visible. Hiding the Icon column collapses the icon space so the Name column gains the extra room. Column visibility persists across restarts.

Reordering Columns

Right-click any column header and use the submenu at the bottom of the context menu to move a column left or right. For example, right-clicking the header area then choosing "Kind column → Move Left" moves Kind before Size. The Name column is always first and cannot be moved. Column order persists across restarts.

Resizing Columns

Hover over the separator area between any two column headers — the cursor changes to a resize arrow. Drag left or right to adjust the column width. The hit target is wider than the visible separator line, making it easier to grab. All file rows update in real time as you drag. Column widths persist across restarts.

Filtering

Type in the Filter… field in each pane's navigation toolbar to instantly narrow the file list. The filter matches anywhere in the filename and automatically activates that pane as you type.

Click the × button that appears inside the filter field to clear it with one click.

When a filter or tag filter is active the pane's status bar appends (filtered) to the item count so it's always clear you're seeing a subset of the folder.

Subfolder Search

The standard filter only looks at files in the current folder. To search the entire subtree — including nested subfolders — use the magnifying glass button that appears next to the × clear button whenever there is filter text:

  1. Type a name pattern in the Filter… field (e.g. invoice).
  2. Click the 🔍 magnifying glass button to the right of the × button.
  3. A blue search banner appears below the sort header showing "Searching subfolders…" with a spinner while Spotlight gathers results. Once finished it shows "N results in subfolders".
  4. Results from the entire subtree are listed in the pane. You can open, move, copy, or delete them just like any other item.
  5. Click the magnifying glass button again, click Clear search in the banner, or clear the filter text with × to exit search mode and return to the normal folder view.
ℹ️

Subfolder search uses macOS Spotlight. Results depend on Spotlight's index for the target folder. External drives, network shares, or directories explicitly excluded from Spotlight may return no results. Standard in-folder filtering always works regardless of Spotlight availability.

💡

Navigating to a different folder or pressing the back button automatically exits search mode and restores the normal view.

Smart Features

Duplicate Finder

Find identical files anywhere in a folder tree — regardless of filename — and reclaim wasted disk space in seconds.

How to use it

  1. Navigate into a folder in either pane.
  2. Click the Dupes button in the toolbar.
  3. DuPane scans the entire folder tree in the background, comparing file content byte-for-byte.
  4. Duplicate groups appear as the scan progresses. Each group shows all copies with their full paths.
  5. Trash individual copies using the trash icon next to each file, or click Keep First to automatically move all copies except the first (alphabetically by path) to the Trash.
  6. Click Done to close the sheet.

How detection works

Duplicate detection uses a two-pass algorithm that is both fast and accurate:

  1. Size grouping — files are first bucketed by byte size. Only files that share the same size proceed to the next pass, eliminating most non-duplicates with zero I/O overhead.
  2. Content hashing — same-size files are hashed with FNV-1a 64-bit. Two files whose hashes match are identical regardless of name, location, or modification date.

Hidden files are skipped. The scan runs entirely off the main thread so the app stays responsive.

Note: The Dupes button is disabled when the active pane is showing the Computer (all volumes) root. Navigate into a real folder first.

Skip confirmation for filesOff Delete files without showing a confirmation dialog. Off by default as a safety net.
Skip confirmation for directoriesOff Delete folders without a confirmation dialog. Directories always show an item count in the alert as an extra safeguard.
ℹ️

Deleted items are always moved to the macOS Trash — they are never permanently removed immediately. You can recover them from the Trash at any time.

Sidebar

SettingDefaultDescription
Show Places sectionOn Shows the Places section (Home, Applications, Desktop, Documents, Downloads) in the sidebar. Turn off to hide the section entirely.
Show Recents sectionOn Shows the Recents section in the sidebar, listing the last 12 folders you visited. Turn off if you prefer a minimal sidebar.

Within the Places section, each individual location can be toggled on or off independently. Available locations: Home, Applications, Desktop, Documents, Downloads. iCloud Drive and OneDrive appear as additional options when those services are configured on your Mac — both are enabled by default if present.

Export & Import Settings

Open the DuPane menu → Export Settings… to save all your preferences to a .json file. Use Import Settings… to restore them — for example when setting up DuPane on a second Mac. All settings apply immediately without a restart.

Startup Folders

Control where each pane opens when DuPane launches. You can set this independently for the left and right panes.

ModeBehaviour
Default Left pane opens Downloads; right pane opens Computer (all volumes). Recommended starting point.
Remember Last Restores whichever folder was open when you last quit. Each pane remembers independently.
Fixed Folder Always opens a specific folder you choose. Type a path or click Browse… to pick one. Useful for a project you return to every day.
