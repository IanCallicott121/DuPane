FREQUENTLY ASKED QUESTIONS

DuPane
Quick Answers

Common questions, non-obvious features, and tips for getting the most out of DuPane — especially handy if you're coming from Finder.

Getting Started

Moving & Copying Files

How do I copy a file from one pane to the other?

Select the file(s) in one pane, then click the Copy button in the toolbar (the arrow-with-square icon). The direction of the arrow shows which pane is receiving the files. The other pane is always the destination — no need to navigate it first.

You can also right-click and choose Copy to Other Pane from the context menu.

How do I move files instead of copy?

Use the Move button (the arrow-with-circle icon). After the move, the files disappear from the source pane and appear in the destination pane. Alternatively, right-click and choose Move to Other Pane.

You can also drag files between panes — hold ⌥ Option while dropping to copy instead of move.

What happens if a file with the same name already exists at the destination?

A conflict dialog appears with three choices: Overwrite (replace the existing file), Skip (leave the existing file untouched and transfer only the non-conflicting ones), or Keep Both (auto-rename the incoming file with a numeric suffix, e.g. report 2.pdf).

How do I delete a file?

Select the file and press ⌘⌫, or click the Delete (trash) button in the toolbar. Files are always moved to the macOS Trash — they are never immediately and permanently deleted. You can recover them from Trash at any time.

Can I drag files from Finder into DuPane?

Yes. Files dragged in from Finder (or any other app) are always copied into the target pane's current folder. Dragging between DuPane's own panes moves by default; hold ⌥ to copy instead.

Getting Started

Navigation

How do I go up to the parent folder?

Press ⌘↑, or click the up-arrow (↑) in the breadcrumb bar. You can also click any segment of the breadcrumb path to jump directly to that ancestor folder.

How do I go back or forward?

Press ⌘[ to go back and ⌘] to go forward, just like a web browser. Each pane keeps its own independent navigation history.

How do I switch which pane is active?

Click anywhere in the pane you want to activate. The active pane shows a more prominent border. Keyboard shortcuts and toolbar buttons always operate on the active pane.

How do I show hidden files (dotfiles)?

Open Settings (⌘,) → Display → toggle Show hidden files. This applies to both panes immediately and persists across restarts.

The breadcrumb path is truncated — how do I see the full path?

The breadcrumb auto-scrolls to show the deepest (current) folder. Scroll the breadcrumb horizontally to see ancestor folders, or hover over any segment to see its full name. The status bar at the bottom also shows the complete path of the selected item.

Getting Started

Tabs

How do I open a new tab?

Press ⌘T or click the + button at the right end of the tab strip. The new tab opens in the same folder as the current tab.

How do I close a tab?

Click the × button on the tab, or press ⌘⇧W. Pinned tabs cannot be closed until unpinned.

What is a pinned tab and why would I use one?

Pinning a tab captures the folder it was showing at the moment you pinned it. Even if you navigate away inside that tab, clicking the pinned tab again returns you to the captured folder — like a bookmark that lives in the tab strip.

Pinned tabs also survive restarts regardless of startup folder mode. Right-click a tab and choose Pin Tab to pin it. A small pin icon appears in the tab.

How do I reorder tabs?

Right-click the tab you want to move and choose Move to Start, Move Left, Move Right, or Move to End. Options are only shown when they apply (e.g. "Move to Start" is hidden for the first tab).

Can I colour-code my tabs?

Yes. Right-click any tab → Tab Color → pick one of eight colours (Red, Orange, Yellow, Green, Blue, Purple, Pink, Graphite). The colour tints the tab background and persists across restarts. Choose None to clear the tint.

Can I give a tab a custom name?

Yes. Right-click the tab → Rename Tab…. Type any name and click Rename. The custom name persists across restarts. To revert to the automatic folder name, right-click → Reset Tab Name.

Smart Features

Bookmarks

How do I bookmark a folder or file?

Select exactly one item in the file list, then click the Bookmark button in the toolbar (bookmark icon). The item appears in the sidebar under Bookmarks. If the item is already bookmarked, clicking the button (which is now filled/blue) removes the bookmark.

How do I reorder my bookmarks?

Drag a bookmark row up or down in the sidebar to reorder it. You can also right-click a bookmark → Move Up or Move Down.

Can I rename a bookmark to give it a friendlier label?

Yes. Right-click the bookmark in the sidebar → Rename…. Type the new name and press Return. The original file or folder name is unaffected — only the sidebar label changes.

What happens when I click a bookmarked file (not a folder)?

Clicking a bookmarked file opens it in its default application — the same as double-clicking it in Finder. Clicking a bookmarked folder navigates the active pane into that folder.

Smart Features

Command Runner (Terminal)

How do I open the terminal panel?

Press ⌥` (Option + backtick) or click the Terminal button in the toolbar. A shell panel slides up from the bottom of the active pane. Press the same shortcut to hide it.

What directory do commands run in?

Commands run in the pane's current directory — the folder being displayed. When you navigate to a different folder, the next command you run in that pane uses the new directory automatically.

Can I run multi-line scripts?

The Command Runner is designed for single-line shell commands. For complex scripts, use Custom Actions (bolt-circle ⚡ toolbar button) where you can store named scripts that run on selected files.

Advanced

Compare & Sync

How do I compare the two panes?

Navigate both panes into real folders (not Computer root), then click the Compare button in the toolbar. Each row shows a badge: only here (missing from the other pane), newer, older, or different. Click Compare again to exit compare mode.

How do I sync differences from left to right?

In compare mode, click Sync L→R. A confirmation dialog shows what will be copied or overwritten. Click Sync to proceed. Files that exist only on the right side are never deleted — sync only adds or updates, never removes.

Compare doesn't scan inside sub-folders — is that a bug?

No, it's a current limitation. Compare v1 compares the top-level contents of both folders by name, size, and modification date. Recursive folder comparison is planned for a future release. Folders are flagged as "different" if their metadata differs, but their internal contents are not inspected.

Advanced

Custom Actions

What are Custom Actions?

Custom Actions are named shell one-liners that appear at the bottom of the right-click context menu. Select files, right-click, and choose an action to run it on your selection.

In your script, $@ expands to the full paths of all selected files, and $PWD is the current directory. Example: for f in $@; do cp "$f" ~/Desktop/; done copies all selected files to the Desktop.

How do I add a Custom Action?

Click the Actions (⚡) button in the toolbar. In the panel, click the + button at the top, type a name and a shell command, then click Save. The action immediately appears in the right-click menu on any file.

How do I run a shell script file (.sh) from the sidebar?

Click (or double-click) a .sh bookmark in the sidebar. A confirmation dialog warns you that the script may modify files. Click Execute to open the script in Terminal and run it.

Advanced

Duplicate Finder

How do I find duplicate files?

Navigate into a folder in either pane, then click the Dupes button in the toolbar. DuPane scans the entire folder tree, groups identical files by content (regardless of name), and shows the results in a sheet. The Dupes button is disabled when the active pane shows the Computer root (all volumes).

How does duplicate detection work? Does it compare filenames?

No — DuPane compares file content, not names. Two files with different names but identical bytes are detected as duplicates. Files are first grouped by size (which is fast), then files sharing the same size are hashed to confirm they're actually identical. Hidden files are skipped by default.

What does "Keep First" do?

For a group of duplicate files, Keep First moves all copies except the first one (alphabetically by path) to the Trash. The first copy stays untouched. You can also trash individual files using the trash icon next to each row.

Advanced

Colour Tags

How do I add a colour tag to a file?

Right-click the file → Tag → choose a colour. The tag appears as a small coloured dot next to the filename. Tags are fully compatible with Finder — they appear immediately in Finder and in Spotlight searches.

How do I filter the file list by tag?

Open the sidebar (⌥⌘S). The Tags section lists all tags found in the currently visible folders. Click a tag to filter both panes to show only items with that tag. ⌘Click additional tags to filter by multiple tags simultaneously. Click the active tag again to clear the filter.

Advanced

Settings

How do I make DuPane remember which folders were open when I quit?

Open Settings (⌘,) → Startup Folders → change each pane's mode to Remember Last. All open tabs, their names, pinned state, and order are saved automatically and restored on next launch.

How do I switch to dark mode?

Open Settings → Display → Appearance → choose Dark. Or choose System to follow macOS's current appearance. The change applies immediately without relaunch.

The toolbar is too crowded — can I hide the button labels?

Open Settings → Display → turn off Show toolbar button labels. Buttons show icons only, saving significant horizontal space while keeping full functionality.

How do I resize or reorder the file list columns?

Resize: Hover over a column separator in the header row until the resize cursor appears, then drag.

Reorder: Right-click any column header → use the "Move Left" or "Move Right" options to rearrange columns. The Name column is always first.

Show/hide: Right-click any column header → toggle individual columns on or off. Settings persist across restarts.

How do I get a Quick Look preview without leaving DuPane?

Select one or more files and press Space. The Quick Look panel floats above DuPane. You can navigate to a different file while the panel is open and it updates automatically. Press Space again to dismiss it.

How do I navigate directly to a folder by typing its path?

Press ⌘L (or use the Toolbar) to open the Go to Folder sheet. Type or paste any absolute path (e.g. /usr/local/bin) or use ~ for your home directory. Press ↩ or click Go to navigate. If the path is not a folder, an error message appears in the status bar.

How does type-ahead file selection work?

With the file list focused, just start typing any letters. DuPane selects the first file whose name starts with the characters you've typed. After 0.6 seconds of inactivity the buffer resets, so you can start a new search. Type-ahead is ignored when a text field (search, filter, rename, etc.) is focused.

How do I change the date format in the Modified column?

Open Settings (⌘,) → Display → Date format. Choose from: Short (31/12/25), Medium (31 Dec 2025 — default), Long (December 31, 2025), ISO (2025-12-31), or Relative (Today, Yesterday, 3d ago). The change applies to both panes immediately.

Can I hide file icons to get more space for the file name?

Yes. Right-click any column header → toggle Icon off. When icons are hidden, the Name column expands automatically to fill the space, and the column header aligns correctly. The setting persists across restarts.

How do I use themes (Ocean, Country, Fire, etc.)?

Open Settings (⌘,) → Appearance → Theme dropdown. The app includes 8 themes: System, Light, Dark, Ocean (dark + cyan), Country (light + forest green), Earth (light + terracotta), Fire (dark + red-orange), and Vivid (light + electric purple). Each theme changes both the color scheme and the accent color used throughout the interface.

How do Places and Recents in the sidebar work?

Places shows fixed system locations (Home, Applications, Desktop, Documents, Downloads). Choose which ones appear in Settings → Sidebar Places.

Recents automatically tracks the last 12 folders you visited in either pane. The most recent is always at the top. Right-click any entry to remove it, or click Clear Recents at the bottom of the section to reset the list.

Network & Servers

How do I connect to a network share (SMB, AFP, NFS)?

Make sure Settings → Sidebar → Show Network section is on, then click Connect to Server… at the bottom of the sidebar. Enter the server address (e.g. smb://server/share) and press ⏎ or click Connect. macOS will prompt for credentials if the share isn't already in Keychain and mount it under /Volumes/.

How do I find servers on my local network without knowing their addresses?

Enable Settings → Network → Bonjour discovery in Connect sheet. When you open the Connect to Server sheet, DuPane scans your local network using Bonjour and lists discovered SMB and AFP servers. Click any result to populate the address field automatically.

How do I unmount (eject) a network share?

Mounted shares appear in the Network sidebar section. Click the Eject button (⏏) on the right of any mounted-volume row. DuPane calls NSWorkspace.unmountAndEjectDevice which cleanly disconnects the share.

Can I save a server address so I don't have to type it every time?

Yes — once a share is mounted it appears in the Network sidebar section. Right-click it and choose Pin to Network Sidebar. The server URL is saved persistently and the entry stays in the sidebar even when the share is not mounted. Click it any time to reconnect, or right-click for Remove from Pinned.

Can DuPane automatically reconnect to a server on startup?

Enable Settings → Network → Auto-reconnect pinned servers on launch (off by default). On the next launch DuPane will silently attempt to mount each pinned server. This works without a prompt when the credentials are stored in the macOS Keychain from a previous connection.

What does the coloured dot next to a network entry mean?

A ● green dot means the share is currently mounted and accessible. A ● grey dot means the server is pinned but not currently mounted. Toggle the indicator with Settings → Network → Show status indicator.
