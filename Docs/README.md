# /Opus

A native macOS dual-pane file manager built with SwiftUI, modelled on
Directory Opus. Real, unsandboxed code that moves, copies, renames, and
trashes actual files.

## Features

**Dual-pane layout**
- Left pane opens at `~/Downloads` by default; right pane shows "Computer" — a
  live list of every mounted volume.
- Each pane is fully independent: its own location, sort, filter, and selection.

**Navigation**
- Back, forward, and up buttons with a real per-pane history stack.
- Clickable breadcrumb trail from Computer down to the current folder.
- Double-click a folder to enter it.

**File list**
- Sortable columns: Name, Size, Kind, Modified — click a header to sort,
  click again to reverse.
- Per-pane filter box for fast narrowing by filename (case-insensitive).
- Native multi-select: single click, ⌘-click (toggle), shift-click (range).
- Status bar shows item count, selection count, and total size of selected files.

**File operations**
- **Move Selected / Copy Selected** — global toolbar buttons act on the active
  pane's selection, targeting the other pane's current folder.
- **New Folder** (⌘N) — prompts for a name and creates it in the active pane.
- **Delete** (⌘⌫) — moves selected items to Trash after a confirmation prompt.
- **Rename** — right-click a file and choose Rename, or use the context menu.
- **Reveal in Finder** — right-click any item.
- Double-click a file to open it in its default app via `NSWorkspace`.
- Toast notifications confirm completed operations.

**Known limitations**
- No drag-and-drop between panes yet — use the toolbar or context menu instead.
- Move/Copy operates on selected files only; selected folders are skipped.
- Breadcrumbs show raw folder names (e.g. `/` rather than "Macintosh HD").
- Deployment target is macOS 13 (Ventura).

## Getting started

**Open and run in Xcode**

```
File → Open… → DOpusMac.xcodeproj
⌘R to build and run
```

The project is generated by [xcodegen](https://github.com/yonaskolb/XcodeGen)
from `project.yml`. If you edit `project.yml` (to add a file group, change
build settings, etc.), regenerate with:

```
xcodegen generate
```

**Run primitive tests without Xcode**

```bash
cd DOpusMac
swift test
```

**Run end-to-end UI tests**

Open `DOpusMac.xcodeproj` in Xcode and press ⌘U, or use the Test navigator.
The UI test scheme (`DOpusMacEndToEndUITests`) launches a real instance of the
app against a temporary fixture directory.

**First-run permissions**

macOS will prompt for access to `~/Downloads` and any removable volumes the
first time they are opened. Click Allow, or grant access manually in
System Settings → Privacy & Security → Files and Folders.

## Project structure

```
DOpusMac/
  project.yml                — xcodegen spec; edit this, then run xcodegen generate
  DOpusMac.xcodeproj         — generated Xcode project; do not hand-edit
  Package.swift              — library + primitive test targets for swift test
  Resources/
    Info.plist               — bundle ID, display name, privacy usage strings
    DOpusMac.entitlements    — app-sandbox = false
  Sources/DOpusMac/
    DOpusMacApp.swift          — @main entry point (Xcode app target only)
    Models/
      FileItem.swift           — value type for a file or folder
      FileOperationService.swift — move, copy, trash, create folder, rename
      AppLaunchConfiguration.swift — parses --left-pane-url / --right-pane-url
      PaneSide.swift           — left / right enum
      PaneStatusFormatter.swift — status bar text
      SortKey.swift            — name / size / kind / modified
    ViewModels/
      PaneState.swift          — navigation history, loading, sorting, selection
    Views/
      ContentView.swift        — wires both panes and cross-pane operations
      PaneView.swift           — single pane: toolbar, file list, context menu
      GlobalToolbar.swift      — Move Selected / Copy Selected / New Folder / Delete
      FileRowView.swift        — one row in the file list
      TitleBar.swift
      DividerBadge.swift
      TextPromptSheet.swift    — shared sheet for New Folder and Rename prompts
      RowMouseEventView.swift  — NSView overlay that captures mouse-down events
  Tests/DOpusMacUITests/       — primitive unit, click, function, and latency tests
  UITests/
    DOpusMacEndToEndUITests/   — XCUIApplication end-to-end tests (Xcode only)
  TODO.md                    — work log: completed items and remaining tasks
```
